网页笔记路由器隐私政策

生效日期：2026 年 7 月 25 日

1. 产品用途

网页笔记路由器用于在用户主动复制网页文字时，通过用户配置的 DeepSeek API 判断笔记分类，并将内容写入用户明确授权的本地 Markdown 目录。

2. 处理的数据

只有在用户主动选择网页文字并执行复制操作时，扩展才会处理：

  • 用户选中并复制的网页文字；
  • 当前网页标题和网址；
  • 路由标签、目标文件及模型设置；
  • 用户自行提供的 DeepSeek API Key；
  • 最近一次笔记保存结果。

扩展不会读取用户未主动复制的网页正文，不会收集密码或支付信息，也不会在后台持续记录浏览历史。

3. 数据用途和共享

复制文字、网页标题和网址会发送至用户配置的 DeepSeek API，唯一用途是生成笔记标题并选择路由标签。DeepSeek 对数据的处理受其自身隐私政策和服务条款约束。

开发者不会出售或出租用户数据，也不会将其用于广告、信用评估或其他无关用途。

4. 本地存储

API Key、模型和路由设置存储在用户本机的 Chrome 扩展存储中。原始笔记写入用户通过系统目录选择器授权的本地目录。开发者不运营用于接收或保存笔记的服务器。

5. 权限说明

  • storage：保存用户设置和最近一次保存结果；
  • notifications：显示保存成功或失败通知；
  • api.deepseek.com：向 DeepSeek 发送用户主动复制的内容完成分类；
  • 网页内容脚本：监听用户主动复制并读取当次选中文字、标题和网址；
  • 本地目录权限：仅访问用户主动选择和授权的目录。

6. 数据控制与删除

用户可以暂停扩展、删除 API Key、修改路由、撤销目录权限，或卸载扩展以清除扩展本地设置。用户可自行删除生成的 Markdown 文件。

7. 数据安全

扩展使用 HTTPS 与 DeepSeek 通信。API Key 仅保存在本机扩展存储中，但能够访问该 Chrome 用户配置或本机账户的人可能读取这些数据。

8. 儿童隐私

本扩展不面向儿童，也不会有意收集儿童个人信息。

9. 政策更新

如果数据处理方式发生变化，本政策将同步更新生效日期和相关说明。
